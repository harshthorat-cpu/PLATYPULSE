# PN532 Module
<br>
The PN532 is a highly integrated transmission module for contactless communication at 13.56 MHz including microcontroller functionality based on an 80C51 core with 40 Kbytes of ROM and 1 Kbytes of RAM. 
<br>

---

## CPU Frequency & Operational States
The PN532 operates under three distinct internal states depending on active communication demands:

* **WAIT:** The default idle state when the PN532 is not actively managing communication with either the host controller or an external RF device.<br>
* **HOST:** Active state when the PN532 is actively exchanging data (reception or transmission) with the host microcontroller.<br>
* **RFCOM:** Active state when the PN532 is managing data exchange over the 13.56 MHz RF channel.<br>

---

## Host controller Interfaces<br>
The system host controller can communicate with the PN532 by using the SPI, I2C or HSU (High Speed UART) serial links. Only one link can be used at once, and the choice is done by a hardware configuration (Interface mode lines I0-I1) during the power up sequence of the chip.<br>
| Interface | Selection Pin I0 (pin #16) | Selection Pin I1 (pin #17) |
| :--- | :---: | :---: |
| **HSU** | 0 | 0 |
| **I2C** | 1 | 0 |
| **SPI** | 0 | 1 |
| **RFU** | 1 | 1 |

## Error Handling<br>
If an operation fails, the PN532 returns a specific application-tier error byte. The status code can be cross-referenced below to identify execution faults:

| Error Cause | Error Code |
| :--- | :---: |
| **Time Out:** The target has not answered | `0x01` |
| **CRC Error:** Detected by the Contactless Interface Unit (CIU) | `0x02` |
| **Parity Error:** Detected by the CIU | `0x03` |
| **Bit Count Error:** Erroneous bit count detected during anti-collision/select (ISO/IEC14443-3 Type A / ISO/IEC18092 106 kbps passive mode) | `0x04` |
| **Framing Error:** Framing error during Mifare operation | `0x05` |
| **Bit-Collision Error:** Abnormal bit-collision detected during bitwise anti-collision at 106 kbps | `0x06` |
| **Buffer Insufficient:** Communication buffer size insufficient | `0x07` |
| **RF Buffer Overflow:** Detected by the CIU (`bit BufferOvfl` of register `CIU_Error`) | `0x09` |
| **RF Field Error:** Active communication mode counterpart failed to switch on RF field in time (NFCIP-1 standard) | `0x0A` |
| **RF Protocol Error:** Protocol anomaly detected within the `CIU_Error` register structure | `0x0B` |
| **Temperature Error:** Internal temperature sensor detected overheating; antenna drivers automatically deactivated | `0x0D` |
| **Internal Buffer Overflow:** Internal memory ring-buffer limit exceeded | `0x0E` |
| **Invalid Parameter:** Parameter out of range, incorrect format, or unsupported option | `0x10` |

## Miscellaneous Commands <br>
This table summarizes the core command codes used to interact with the PN532 firmware.
| Command Name | Code | Purpose |
| :--- | :---: | :--- |
| **`Diagnose`** | `0x00` | Run self-tests (e.g., Antenna health). |
| **`GetFirmwareVersion`** | `0x02` | Retrieve version, revision, and support mask. |
| **`GetGeneralStatus`** | `0x04` | Get system status, error flags, and target count. |
| **`ReadRegister`** | `0x06` | Read data from internal/XRAM registers. |
| **`WriteRegister`** | `0x08` | Write data to internal/XRAM registers. |
| **`ReadGPIO`** | `0x0C` | Read status of Port 3, Port 7, and I0/I1 lines. |
| **`WriteGPIO`** | `0x0E` | Update output states of Port 3 and Port 7. |
| **`SetSerialBaudRate`** | `0x10` | Configure HSU baud rate. |
| **`SetParameters`** | `0x12` | Update firmware operational flags. |
| **`SAMConfiguration`** | `0x14` | Configure Security Access Module (SAM) routing. |
| **`PowerDown`** | `0x16` | Put the chip into low-power sleep mode. |
